# ISO 9001

> **Estado:** placeholder. Es la norma "base" — la mayoría de los demás regímenes (IATF 16949, AS 9100, ISO 13485) la incluyen.

## Qué exige (resumen)

- Sistema de gestión de calidad documentado.
- Procesos definidos, medidos y mejorados.
- Acciones correctivas y preventivas (CAPA).
- Auditorías internas periódicas.
- Revisión por la dirección.

## Implicaciones en nuestro código

1. **Documentación viva** de procesos clave del MES (este repo es parte del SGC).
2. **CAPA workflow** en `apps/quality/` (mismo modelo que NCR + acción correctiva con plazo + verificación de eficacia).
3. **Reportes de KPIs** disponibles para revisión por dirección (OEE, FPY, ratio NCR/lotes).

# IATF 16949

> **Estado:** placeholder. Aplica a casi cualquier proveedor automotriz. Architect debe completar antes de Fase 4 (Quality / NCR).

## Qué exige (resumen)

- Trazabilidad obligatoria al lote/serie de cada componente crítico.
- Control de cambios de ingeniería con aprobación documentada.
- Análisis de modos de falla (FMEA) para procesos críticos.
- Plan de control con frecuencia de inspección por característica.
- Registro de no conformidades con análisis 8D / 5 porqués / Ishikawa.
- PPAP (Production Part Approval Process) para nuevos productos.

## Implicaciones en nuestro código

1. **Trazabilidad genealógica completa** desde materia prima hasta producto terminado (ya en el roadmap, Fase 2).
2. **Plan de control** modelado en `apps/quality/`: frecuencia, característica, especificación, método.
3. **Workflow 8D** para NCRs: cada paso debe quedar registrado con responsable y fecha.
4. **Cambios de ingeniería** disparan revisión de plan de control y BOM.
